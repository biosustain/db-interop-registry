Building locally
----------------

1. Install docs dependencies: ``pip install -r requirements-dev.txt``
2. Build HTML: ``make -C docs html`` (outputs to ``docs/_build/html``)
3. View the docs: open ``docs/_build/html/index.html`` in a browser
